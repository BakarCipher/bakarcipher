## 🧭 MY CYBERSECURITY JOURNEY

*From writing my first programs to developing cybersecurity tools and exploring real-world defense operations.*

</div>

### `01 // THE FOUNDATION — LEARNING TO BUILD`

My journey started with programming, networking fundamentals, operating systems, and understanding how computers communicate.

I developed experience with **C, C++, Java, Python, C#, and web technologies**, while exploring networking concepts such as TCP/IP, subnetting, routing, switching, VLANs, and network troubleshooting.

**What I learned:** Before securing a system, you must understand how it works.

### `02 // ENTERING THE SECURITY WORLD`

As a Cyber Security student at **Riphah International University**, I began exploring practical offensive and defensive security techniques.

My academic labs introduced me to:

- Kali Linux and security testing environments
- Wireshark and TCP/IP packet inspection
- Nmap scanning and service enumeration
- Snort intrusion detection and custom rules
- Linux firewalls, UFW, and iptables
- Nessus vulnerability assessments
- Wazuh security monitoring
- Virtual machines and isolated security labs

**What I learned:** Cybersecurity is not just about tools. It is about understanding evidence, identifying weaknesses, and applying the right controls.

### `03 // BUILDING THE BAKARCIPHER ECOSYSTEM`

### `04 // DEVELOPING REAL-WORLD DEFENSIVE SKILLS`

My practical training focuses on developing the mindset and technical abilities needed for security operations.

Areas of ongoing learning include:

**Career Direction:** Continuing to grow toward cybersecurity roles involving security operations, threat detection, and incident response.
